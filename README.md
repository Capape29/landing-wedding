# landing-wedding

SPA de invitación de boda construida con **React + Vite + Tailwind CSS**.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Configuración RSVP (Google Sheets)

Define la URL del Google Apps Script en un archivo `.env`:

```bash
VITE_GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/TU_SCRIPT_ID/exec
```

Coloca la canción principal en `/public/audio/cancion.mp3`.
